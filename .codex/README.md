# Codex Overlay

Use this repository as the Codex entrypoint for Interface Assembly.

Read first:

- `README.md` — what Interface Assembly is and how to start
- `constitution.md` — the rules of clause coding
- `world/WORLD.md` — the current named world and its boxes
- `world/clauses/` — one file per box
- `hub/README.md` — available skills and agents
- `agents/vendor/skill-hub-registry.json` — registered agents

Rules:

- Read the world before building anything.
- Clauses define the boundaries. Do not violate them.
- What a box OWNS, only that box controls.
- Propose new clauses before writing code inside a new boundary.
- No crypto, no env variables, no commercial infrastructure in this repo.
- This is a non-commercial beginner-friendly starter kit. Keep it that way.
