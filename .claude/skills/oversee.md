# /oversee - WorldBuilder Review

Use `/oversee` to run a full coherence review of the world.

---

## Read First

1. `world/WORLD.md`
2. all files in `world/clauses/`
3. all files in `world/interfaces/`
4. all files in `world/adapters/`
5. all files in `world/proposals/`
6. all files in `world/amendments/`
7. all files in `agents/arbiter/conflicts/`
8. `world/merkle/current.md`
9. latest gistbook snapshot
10. latest public-readiness report if one exists

---

## Review Questions

1. Does every new thing have the right classification?
2. Are any shared contracts still trapped inside clauses?
3. Are adapters staying at the edge?
4. Are block agents staying scoped to one block?
5. Are cross-box changes being routed through owner participation?
6. Does the merkle root match the listed tokens?
7. Is the repo ready to be published, or is PublicReadiness still blocked?

---

## Outputs

Write the review to `agents/worldbuilder/log/`.

If a final ratified boundary decision is made, also record it in `agents/worldbuilder/decisions/`.
